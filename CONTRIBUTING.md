# Как помочь курсу

Спасибо, что хочешь сделать курс лучше! Самые полезные вклады:

1. **Битая или устаревшая ссылка** — Issue с названием `Ссылка: <раздел>` и рабочей заменой, если знаешь.
2. **Новый ресурс** — только если он бесплатный или с бесплатной частью, актуален в 2026 году и лучше того, что уже есть в разделе. В PR напиши одну строку «почему он лучше».
3. **Ошибка в схеме или коде** — Issue с фото сборки, текстом ошибки и версией платы/библиотеки (шаблон — в [docs/debugging.md](docs/debugging.md#8-шаблон-баг-репорта-для-себя-и-для-readme-проекта)).
4. **Свой проект по курсу** — Issue с меткой `showcase`: видео, ссылка на репозиторий, цифра результата. Лучшие попадут в README.

## Правила для PR
- Одна тема — один PR.
- Ресурсы оформляй как в README: `[Название](ссылка)` + почему стоит смотреть (одно предложение).
- Никаких ROS 1-туториалов (`catkin`, `rosrun`) и Gazebo Classic — курс на ROS 2 Jazzy + Gazebo Harmonic.
- Код примеров: комментарии на русском, схема подключения в шапке файла, без внешних библиотек, если можно обойтись.
- Python-примеры должны запускаться командой `python file.py` без железа.
