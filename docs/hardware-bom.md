# Списки компонентов (BOM)

Цены — ориентировочные (USD, осень 2026, официальные магазины). На AliExpress аналоги обычно в 2–5 раз дешевле, но дольше и без гарантии.

## Уровень 0 — $0
- [Falstad](https://www.falstad.com/circuit/), [Tinkercad Circuits](https://www.tinkercad.com/circuits), [Wokwi](https://wokwi.com/) (симулятор ESP32/Arduino в браузере)
- ROS 2 + Gazebo в Docker, MuJoCo
