# Глоссарий: термины робототехники (RU ↔ EN)

Англоязычные термины пригодятся при поиске: почти вся документация на английском.

## Электроника
| Русский | English | Коротко |
|---|---|---|
| Напряжение / ток / сопротивление | voltage / current / resistance | U = I·R (закон Ома) |
| Делитель напряжения | voltage divider | два резистора, понижают напряжение |
| Подтягивающий резистор | pull-up / pull-down resistor | задаёт уровень входа, когда кнопка не нажата |
| Развязывающий конденсатор | decoupling capacitor | 100 нФ у питания микросхемы, гасит помехи |
| ШИМ | PWM (pulse-width modulation) | регулировка мощности быстрым включением/выключением |
| Скважность (коэффициент заполнения) | duty cycle | доля времени «включено» в ШИМ |
| H-мост, драйвер мотора | H-bridge, motor driver | позволяет крутить мотор в обе стороны |
| Стабилизатор / DC-DC | voltage regulator / buck converter | делает стабильные 5 В или 3.3 В |
| Общая земля | common ground | все GND соединены — иначе сигналы «не понимают» друг друга |
| Логические уровни | logic levels | 3.3 В у ESP32, 5 В у Arduino UNO |

## Микроконтроллеры
| Русский | English | Коротко |
|---|---|---|
| Микроконтроллер (МК) | microcontroller (MCU) | Arduino, ESP32, STM32 |
| Прерывание | interrupt (ISR) | функция, вызываемая аппаратно по событию |
| Антидребезг | debounce | фильтр ложных срабатываний кнопки |
| Последовательный порт | serial / UART | обмен текстом/байтами по двум проводам |
| Шины I2C / SPI | I2C / SPI bus | подключение датчиков |
| Прошивка | firmware | программа МК |
| Реальное время | real-time | гарантированное время реакции |

## Механика и приводы
| Русский | English | Коротко |
|---|---|---|
| Редуктор / передаточное число | gearbox / gear ratio | меняет скорость на момент |
| Крутящий момент | torque | кг·см или Н·м |
| Люфт | backlash | «мёртвый ход» в передаче |
| Сервопривод | servo | мотор со встроенной обратной связью по углу |
| Шаговый двигатель | stepper motor | поворачивается дискретными шагами |
| Бесщёточный мотор | BLDC motor | высокая мощность, нужен контроллер (FOC) |
| Энкодер | encoder | датчик поворота вала |
| Степень свободы | DoF (degree of freedom) | число независимых движений |
| Схват / захват | gripper / end effector | «кисть» робота |

## Управление и оценка состояния
| Русский | English | Коротко |
|---|---|---|
| Замкнутый контур | closed loop / feedback | измеряем → сравниваем с целью → корректируем |
| ПИД-регулятор | PID controller | пропорциональная, интегральная, дифференциальная части |
| Насыщение интегратора | integrator windup | интеграл «разбухает» при упоре в предел |
| Упреждающее управление | feedforward | подаём «ожидаемое» управление сразу |
| Пространство состояний | state space | описание системы вектором состояния |
| Линейно-квадратичный регулятор | LQR | оптимальный регулятор для линейной модели |
| Управление с прогнозирующей моделью | MPC | оптимизация управления на горизонт вперёд |
| Фильтр Калмана | Kalman filter (KF/EKF/UKF) | оптимальное слияние шумных измерений |
| Комплементарный фильтр | complementary filter | простое слияние гироскопа и акселерометра |
| Инерциальный датчик | IMU | акселерометр + гироскоп (+ магнитометр) |
| Слияние датчиков | sensor fusion | объединение данных разных сенсоров |
| Одометрия | odometry | оценка положения по колёсам |

## Кинематика и планирование
| Русский | English | Коротко |
|---|---|---|
| Прямая / обратная кинематика | forward / inverse kinematics (FK/IK) | углы → положение / положение → углы |
| Система координат, фрейм | coordinate frame | `base_link`, `odom`, `map` |
| Преобразование | transform (TF) | положение одного фрейма относительно другого |
| Кватернион | quaternion | способ хранить ориентацию без «складывания рамок» |
| Планирование движения | motion planning | поиск пути без столкновений |
| Одновременная локализация и картирование | SLAM | строим карту и находим себя на ней |
| Карта стоимости | costmap | карта «где ехать опасно» в Nav2 |

## ROS 2
| Термин | Коротко |
|---|---|
| Node (нода) | отдельная программа-процесс |
| Topic (топик) | поток сообщений «публикатор → подписчики» |
| Service (сервис) | запрос → ответ |
| Action (экшен) | долгая задача с прогрессом и отменой |
| Parameter (параметр) | настройка ноды, меняется на лету |
| Launch file | запуск нескольких нод с настройками |
| QoS | правила доставки (надёжно / быстро, история) |
| URDF / xacro | описание робота (звенья, суставы) / макросы для URDF |
| ros2_control | слой между контроллерами и железом |
| Nav2 | стек навигации |
| MoveIt 2 | планирование движений манипулятора |
| rosbag | запись и воспроизведение топиков |
| colcon | система сборки рабочего пространства |

## Обучение роботов
| Термин | Коротко |
|---|---|
| Imitation learning / behavior cloning | обучение по демонстрациям человека |
| Teleoperation (телеуправление) | человек управляет роботом, записываются данные |
| Policy (политика) | модель «наблюдение → действие» |
| ACT, Diffusion Policy | популярные архитектуры политик для манипуляции |
| VLA (vision-language-action) | модель: картинка + текстовая команда → действия робота |
| Reinforcement learning (RL) | обучение методом проб и ошибок по награде |
| Sim-to-real | перенос политики из симуляции на реального робота |
| Domain randomization | случайные параметры симуляции, чтобы политика была устойчивой |
