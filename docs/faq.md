# FAQ — частые вопросы

**Нужно ли высшее техническое образование?**
Нет. Работодателям важнее работающие проекты на реальном железе, C++ и Python, и умение отлаживать. Математика нужна, но её можно доучивать по ходу (модуль 5).

**Какой минимум математики нужен на старте?**
Школьная алгебра и тригонометрия (sin, cos, atan2). Линейная алгебра (матрицы, векторы) нужна к модулю 4–5 — рекомендую [Essence of Linear Algebra (3Blue1Brown)](https://www.youtube.com/playlist?list=PLZHQObOWTQDPD3MizzM2xVFitgF8hE_ab).

**Какой компьютер нужен?**
Любой ноутбук за последние 6–7 лет с 8+ ГБ ОЗУ (лучше 16). GPU не нужен до модуля 6; для обучения политик можно использовать Google Colab или Kaggle.

**У меня Windows / macOS. ROS 2 только на Linux?**
Удобнее всего Ubuntu 24.04 (dual boot или отдельный диск). Альтернативы: WSL2 на Windows, Docker (`osrf/ros:jazzy-desktop`), виртуальная машина, браузерная The Construct. На macOS — Docker или VM; нативная поддержка ограничена.

**Arduino или сразу ESP32?**
Начни с Arduino UNO из стартового набора (больше всего туториалов), через 1–2 недели переходи на ESP32-S3 — он дешевле, мощнее и с Wi-Fi.

**Где брать железо, если AliExpress идёт долго?**
Первый набор — из локального магазина (Амперка, Чип и Дип, маркетплейсы). Расходники, датчики, моторы для экспериментов — AliExpress, заказывай заранее, пока проходишь модуль 1 в симуляторах.

**Можно ли пройти курс без 3D-принтера?**
Да. Фаблабы, мейкерспейсы, онлайн-сервисы печати; рука SO-101 продаётся с готовыми печатными деталями; есть EEZYbotARM и симуляция в MuJoCo.

**Python или C++?**
Оба. Python — быстрое прототипирование, ML, скрипты. C++ — МК, ROS 2 в продакшене, всё, где важна скорость. Начинай с Python, C++ появится естественно на Arduino и в ROS 2.

**Почему ROS 2 Jazzy, а не новейший Lyrical?**
Почти все курсы и книги сейчас на Jazzy, поддержка до 2029. Когда освоишься, перейти на Lyrical — несколько вечеров.

**Сколько реально стоит весь курс?**
От $0 (только симуляция) до ~$600–900 со всем железом, включая руку SO-101 и ровер с лидаром. Минимальный разумный бюджет для «настоящих» роботов — ~$150–250. См. [hardware-bom.md](hardware-bom.md).

**Я застрял на ошибке. Где спросить?**
Сначала [debugging.md](debugging.md). Затем: [Robotics Stack Exchange](https://robotics.stackexchange.com/), [ROS Discourse](https://discourse.openrobotics.org/), Telegram-чат [ROS Russia](https://t.me/rosrussia), Issues этого репозитория. Как спрашивать: что делал, что ожидал, что получил, полный текст ошибки, фото схемы.

**Как найти первую работу/стажировку?**
Портфолио из 4–5 проектов с видео + отклики на позиции junior robotics / embedded / ROS-разработчик. Помогают соревнования (Eurobot, RoboCup, «Робофест», НТО), хакатоны, вклад в open-source (LeRobot, Nav2, ros2_control — у всех есть issues с меткой `good first issue`).
