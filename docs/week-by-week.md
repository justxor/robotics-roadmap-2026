# План по неделям (24 недели × 2–3 часа в день)

Ориентир, а не закон: если неделя растянулась на две — нормально. Главное правило — **каждую неделю что-то должно двигаться или светиться**, и каждую неделю — коммит на GitHub.

Обозначения: 💻 — можно без железа, 🔧 — нужно железо, 📹 — снять видео для портфолио.

## Если времени меньше

| Время в день | Как идти |
|---|---|
| 1 час | растяни на 12 месяцев: одна неделя плана = две календарные |
| 2–3 часа | по плану |
| 5+ часов | можно за 3–4 месяца, но не пропускай практику ради скорости |
