## Как сделать проект «нанимаемым»
1. **Проблема** в первом предложении README («Робот должен проезжать квадрат с ошибкой < 5 см»).
2. **Видео** до кода.
3. **Цифра** результата и как измерял.
4. **Что сломалось** — 3–5 пунктов.
5. **Что бы улучшил** — показывает, что ты понимаешь ограничения.
