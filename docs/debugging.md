# Отладка роботов: чек-листы «не работает — что проверить»

> Правило №1: **меняй одну вещь за раз** и записывай, что поменял.
> Правило №2: сначала питание, потом провода, потом код.

## 1. Ничего не включается / МК перезагружается

- [ ] Мультиметром: напряжение на батарее **под нагрузкой** (просаженная LiPo показывает норму без нагрузки).
- [ ] Есть ли **общая земля** у МК, драйвера, датчиков и батареи?
- [ ] Перезагрузка при старте моторов → просадка питания: отдельный DC-DC для логики, 470 мкФ у драйвера, не питай моторы от USB.
- [ ] Ток: моторы в стопоре берут в 5–10 раз больше номинала — хватает ли стабилизатора/драйвера?
- [ ] Ни одного 5 В сигнала на вход ESP32 (3.3 В логика!) без делителя или преобразователя уровней.
- [ ] Холодная пайка, перепутанные VCC/GND на модуле — прозвонка.

## 2. ESP32 / Arduino не прошивается

| Симптом | Что делать |
|---|---|
| Порт не появляется | кабель «только зарядка» → другой кабель; драйвер CP210x / CH340 |
| `Failed to connect… Timed out waiting for packet header` | зажми BOOT во время «Connecting…»; отключи провода с GPIO 0, 2, 12, 15 |
| Прошилось, но не стартует | GPIO 12 подтянут к HIGH при старте → перенеси провод |
| В Serial «кракозябры» | скорость монитора ≠ `Serial.begin(...)` |
| Linux: `Permission denied /dev/ttyUSB0` | `sudo usermod -aG dialout $USER` и перелогинься |

## 3. Моторы

| Симптом | Причина / решение |
|---|---|
| Мотор пищит, но не крутится | мало ШИМ (мёртвая зона) или мало напряжения; на TB6612 STBY = HIGH? |
| Крутится в обратную сторону | поменяй провода мотора или инвертируй в коде |
| Одно колесо быстрее другого | так всегда — для этого нужен PID по энкодерам |
| Драйвер горячий | L298N — замени на TB6612FNG/DRV8833; или ток выше допустимого |
| Энкодер считает «не туда» | поменяй местами каналы A/B |
| Энкодер считает рывками/с пропусками | нет подтяжки на GPIO 34–39, помехи от мотора → экранированный провод, 100 нФ на моторе |

## 4. Датчики (I2C)

- [ ] Запусти I2C-сканер — видит ли МК адрес (MPU-6050: 0x68/0x69, VL53L0X: 0x29, BNO085: 0x4A/0x4B)?
- [ ] SDA/SCL не перепутаны? На ESP32 по умолчанию SDA = 21, SCL = 22.
- [ ] Подтяжки 4.7 кОм на SDA/SCL (у большинства модулей уже есть).
- [ ] Два датчика с одним адресом → у одного смени адрес (AD0, XSHUT) или используй мультиплексор TCA9548A.
- [ ] Длинные провода (> 30 см) → снизь частоту `Wire.setClock(100000)`.

## 5. Управление (PID)

| Поведение | Что крутить |
|---|---|
| Медленно, «не дотягивает» | ↑ Kp, добавь немного Ki |
| Раскачка вокруг цели | ↓ Kp или ↑ Kd |
| Дрожь, шум | ↓ Kd или отфильтруй производную |
| Долго «уплывает» после насыщения | anti-windup: ограничь интеграл |
| Работало и перестало при севшей батарее | добавь feedforward по напряжению или PID по скорости (энкодеры) |

**Всегда логируй:** цель, измерение, выход регулятора — и смотри в Serial Plotter / PlotJuggler. Настройка «на глаз» без графиков — потеря времени.

## 6. ROS 2

| Симптом | Проверка |
|---|---|
| `ros2: command not found` | `source /opt/ros/jazzy/setup.bash` (добавь в `~/.bashrc`) |
| Пакет не находится после сборки | `source install/setup.bash` в **каждом** новом терминале |
| Топик публикуется, но никто не получает | `ros2 topic info -v /topic` — совпадают ли QoS (reliable/best_effort)? |
| Ноды на двух компьютерах не видят друг друга | одинаковый `ROS_DOMAIN_ID`, одна сеть, файрвол, `ROS_AUTOMATIC_DISCOVERY_RANGE` |
| RViz: «No transform from X to Y» | `ros2 run tf2_tools view_frames` — где разрыв дерева? |
| Робот в Gazebo проваливается / взрывается | нет `<inertial>` или нулевые/огромные инерции |
| SLAM рисует «размытую» карту | одометрия: проверь `WHEEL_BASE`, радиус колеса, тики на оборот |
| Nav2 не едет | costmap «залит» препятствиями (радиус инфляции), нет `map → odom` |
| Нашёл туториал с `catkin_make` / `rosrun` | это ROS 1 — ищи версию для ROS 2 |

Полезные команды:
```bash
ros2 doctor --report          # общая диагностика
ros2 node list && ros2 topic list
ros2 topic hz /scan           # частота
ros2 topic echo /odom --once
rqt_graph                     # граф нод
ros2 bag record -a            # записать всё, разбирать потом
```

## 7. 3D-печать

| Проблема | Решение |
|---|---|
| Деталь не налазит на вал/серво | заложи зазор из своего калибра допусков (обычно 0.2–0.3 мм) |
| Отслаивается от стола | помой стол (IPA/мыло), калибровка Z, кайма (brim) |
| Ломается по слоям | поверни деталь: нагрузка должна идти **вдоль** слоёв, PETG вместо PLA |
| Отверстия меньше модели | так у FDM всегда: +0.2 мм к диаметру или рассверли |
